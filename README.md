# Threshold

Lactate threshold testing, training zones, and non-invasive lactate sensor research.

Live site: [ageoffron.github.io/Threshold](https://ageoffron.github.io/Threshold)

## What's here

- `index.html` — landing page covering lactate testing protocols, zone-based training, and the 2026 sensor landscape (microneedle ISF sensors, sweat biosensors, NIR spectroscopy).

## Roadmap

## Stack

Plain HTML/CSS/JS. No framework. GitHub Pages serves it directly from `main`.
